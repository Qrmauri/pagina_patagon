# Identidad de color de Patagon Store

Paleta tomada como referencia del logo original, sin modificarlo:

| Uso | Color |
| --- | --- |
| Rojo del logo | `#dd1c16` |
| Rojo para acciones y texto | `#c92119` |
| Turquesa del logo | `#03a79e` |
| Turquesa con texto blanco | `#00766f` |
| Amarillo del logo | `#ef9d03` |
| Amarillo claro de apoyo | `#fff4cb` |
| Dorado para texto sobre fondo claro | `#946000` |

Los tonos oscuros mantienen contraste en botones y textos. El amarillo principal
se usa con texto oscuro o como borde. Las categorías repiten los tres colores;
los filtros activos y la información usan turquesa. Las alertas de stock mantienen
su significado. Los alias CSS anteriores se conservan para actualizar también
componentes que ya los utilizan. La tipografía Pooh se mantiene en títulos.

El fondo general usa azul turquesa `#159ba8`, inspirado en la fachada de referencia
aportada por el usuario. Las superficies de lectura son blancas, con bordes
`#d9e3e5`, para mantener legibles los textos y precios. El pie utiliza turquesa
oscuro `#113c3b`.
El rojo y el amarillo quedan como acentos para mantener una presentación sobria.

Los tres tonos base se ajustaron mediante muestreo de los píxeles opacos del PNG
del logo. Los tonos oscuros son variantes deliberadas para facilitar la lectura.
